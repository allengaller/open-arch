# 招投标技术支持

政企与大中型客户采购的必经环节，技术分往往占 40-60 分——SA 是技术分的第一责任人。

## 招投标流程与 SA 介入点

    标前引导（采购需求/技术参数形成期）
      → 招标公告/标书发售
      → 标书解读与投标决策
      → 投标文件编制（技术标 + 商务标）
      → 开标 → 澄清答疑 → 讲标/答辩 → 评标 → 定标

| 节点 | SA 动作 | 要点 |
|---|---|---|
| 标前引导 | 在合规前提下参与技术交流，让真实需求进入采购参数 | 见下方红线 |
| 标书解读 | 逐条拆解技术需求、评分办法、废标项 | 出《标书解读表》，废标项一票否决需全员知会 |
| 技术标编写 | 方案应答、点对点应答、偏离表 | 结构对应评分项，方便评委找分 |
| 澄清答疑 | 书面回复技术澄清 | 口径统一，逐条应答不发散 |
| 讲标答辩 | 现场陈述 + 回答评审团问题 | 见下节 |

**标前引导的红线**（《招标投标法》与公平竞争边界）：

- 可以做：技术交流、方案宣讲、白皮书与标准参与、让客户把**真实业务需求**写进参数。
- 不可做：以排他性参数定向围标串标（"仅限某某品牌""某独有专利"）、虚假参数、与客户串通定制歧视性条款。参数应描述**能力**而非**品牌**——"支持故障自动切换 RTO<15min"合规，"须为 XX 厂商"违规。

## 标书解读表

拿到标书 48 小时内产出，铁三角共同评审：

| 模块 | 拆什么 |
|---|---|
| 评分办法 | 技术/商务/价格分值分布、评分细项逐条列出（技术标按此组织应答结构） |
| 资质门槛 | 我方是否满足；需要伙伴/原厂出具哪些授权与承诺函（提前走流程） |
| 废标项 | 星号/★条款、实质性要求逐条核对，任何一项不满足立即升级决策 |
| 技术需求 | 逐条编号 → 应答策略（完全满足/正偏离/负偏离）→ 责任人 |
| 竞争预判 | 参数倾向哪家、可能同台者、我方胜负手在哪几条 |

## 技术标编写

- **结构映射评分项**：评委按评分表找分，应答章节标题直接引用评分项措辞，别让评委找不到给分的地方。
- **点对点应答**：招标技术需求逐条编号，逐条应答（需求原文 + 应答 + 支撑材料页码索引），不漏条、不合并。
- **偏离表**：正偏离（优于要求，突出差异化）单列强调；负偏离尽量消除，无法消除的评估扣分影响并给补偿性亮点。
- **证明材料**：测试报告、案例合同关键页（脱敏）、检测机构报告、体系认证——评分项"有证明"和"口头承诺"是两档分。
- **一致性自查**：技术标与商务标、报价表的规格数量必须一致，前后矛盾是低级丢单原因；交稿前专人逐页核对。

## 讲标答辩

**准备**：

- 分析评审团构成：技术专家（讲架构与依据）、业务领导（讲价值与案例）、财务（讲 TCO）——不同人问不同类问题，陈述时分层覆盖。
- 预演 ≥ 2 次：完整计时排练 + 模拟提问（Q&A 题库 20-30 条：自己方案的弱点、竞品会攻击的点、标书矛盾点，都提前备好答案）。
- 答辩人分工：SA 主讲技术、BD 补商务与案例，一人主答避免多人抢话。

**15 分钟陈述参考结构**：需求理解与痛点（2min）→ 总体方案与差异化亮点（5min）→ 实施与保障（3min）→ 同类案例（3min）→ 结语呼应评分项（2min）。差异化亮点讲透 1-2 个，胜过全面平庸。

**答辩纪律**：听完整问再答，答不清的承诺"会后书面补充"而不是现场编；不贬损竞品（评委可能就是竞品方案的作者）；不承诺标书之外的免费定制（会被写入合同）。

## 定标与合同技术附件

中标 ≠ 结束：合同技术附件（技术协议、SLA、验收标准）是 SA 的最后防线——投标承诺的技术指标会原样进合同。

- **签前逐条复核可实现性**：资源规格、性能指标、响应时限，逐条对照实际产品能力；投标阶段的"力争"措辞到合同里就是硬承诺。
- **SLA 口径**：可用性承诺与赔付条款对齐产品既有 SLA 档位；超出标准档位的自定义 SLA 必须走产品/法务评审，不拍脑袋。
- **验收标准对齐**：合同验收条款与 POC 成功标准（见 `poc-playbook.md`）拉通，两套口径是验收扯皮的根源。
- **禁区**：不在附件承诺标书外免费定制；拿不准的指标写"双方另行商定测试方案"，不写具体数字。

## 联合体与伙伴投标

政企大单常见联合体/总分结构，SA 要先懂结构再动手：

- **结构选择**：原厂直投（技术分强）、伙伴主投 + 原厂授权背书（属地与集成分强）、联合体（资质互补）——按评分办法反推最优结构。
- **合规边界**：资质与业绩必须真实可溯源，业绩"借用"是废标与法律风险双重雷。
- **SA 动作**：联合体内明确技术方案署名、答辩分工与我方边界；"我方底座 × 伙伴集成"的技术接口在投标前完成预集成验证，不在标书里写没验证过的集成承诺。

## 关键话术

- 技术分是 SA 的军令状：评分项结构 = 应答结构 = 陈述结构，三位一体。
- 正偏离是竞争武器：在对手满足不了的指标上，用可验证的正偏离拉开分差。
- 标书里找不到的答案，评委会在答辩里找——预演题库准备到"最不想被问到的问题"。
- 合规是底线：靠排他参数赢来的单子，输掉的是客户信任和审计风险。
