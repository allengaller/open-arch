# 高频技术场景商机打法

单子按技术场景进来时的打法骨架：客户画像、触发事件、打单要点、高频异议、常见的坑。参考架构细节见 `arch-design` 技能的 `content/patterns.md`，基础概念见 `sa-concepts` 技能；迁移 / AI / 出海 / 招投标已有专篇（`migration-playbook.md`、`ai-solutions.md`、`global-expansion.md`、`bidding-support.md`），本篇不重复。

## 1. 大促 / 高并发弹性

- **触发事件**：大促前 3-6 个月（618/双 11/节假日票务）；信号词："去年挂了""流量涨 X 倍"
- **打单要点**：全链路压测是入口钩子（压出问题才有预算）；方案 = 扩容预案 + 降级预案 + 值守安排三件套；成本账按"大促当日 vs 全年"摊销，别报全年闲置容量
- **高频异议**："买硬件更划算" → 一年只跑 7 天峰值的硬件是沉没成本
- **坑**：预案没演练过（压测通过≠扩容预案有效）；第三方接口（支付/短信）没纳压

## 2. 数据平台 / BI 报表

- **触发事件**："报表跑不动""老板要看实时大屏""数据在各系统孤岛"
- **打单要点**：先做数据盘点（多少系统、多少表、谁消费）再谈平台；入门口子常是"一张老板报表"；治理与血缘前置一句，避免下一年返工预算
- **高频异议**："Excel 够用" → 算分析师手工对账的人力账
- **坑**：一上来推湖仓一体（客户只有 20 张表）；只建平台不管使用（半年后没人登录）

## 3. 混合云 / 信创替换

- **触发事件**：合规/政策要求、现有授权到期、集团信创指标
- **打单要点**：应用改造分级先行（免改造直接替换 / 少量适配 / 需重构），给替代矩阵（芯片-OS-中间件-数据库逐层）；适配测试工作量是最容易漏的预算项
- **高频异议**："改造量太大" → 分批：外围系统先行，核心双轨
- **坑**：性能基准不对等（新架构 vs 老小型机）；生态软件（商业中间件）无国产版本

## 4. 视频直播 / 在线教育

- **触发事件**：开播卡顿事故、活动类目扩张、牌照合规要求
- **打单要点**：链路 = 采集推流 → 转码 → CDN 分发 → 播放端，逐段给质量指标（首帧/卡顿率）；带宽是最大成本项，给"用量阶梯 + 预警"方案
- **高频异议**："CDN 谁家都一样" → 现场测速对比 + 调度策略差异
- **坑**：盗录与防盗链没提前谈；突发流量（爆款活动）的带宽账单惊吓

## 5. IoT / 工业互联网

- **触发事件**：设备上云指标、产线数字化改造、远程运维需求
- **打单要点**：协议接入是第一道坎（Modbus/OPC-UA 等现场协议杂）；方案分层：边缘侧 → 接入 → 平台 → 应用，边缘交付常需要现场实施伙伴
- **高频异议**："设备太老没有接口" → 网关采集过渡方案
- **坑**：低估现场实施（工厂环境、停机窗口）；只卖平台不管设备接入

## 6. SaaS 创业公司托管

- **触发事件**：SaaS 产品客户增长、多租户改造、成本焦虑
- **打单要点**：多租户隔离模式（共享 schema / 独立库）的选择影响成本与合规，越早定越省；成长期用"按量 + 承诺混合"锁价
- **高频异议**："等融资再说" → 免费额度 + 成长阶梯绑定
- **坑**：租户数据隔离返工（后期改造成本 10 倍）

## 7. 等保 / 安全整改驱动

- **触发事件**：等保测评时间点、监管检查、安全事故后
- **打单要点**：时间倒排——测评日期是唯一 deadline；对照测评项出整改清单（日志留存/堡垒机/加密/边界），逐项报价；行业与合规细节见 `industry-compliance.md`
- **高频异议**："预算就这些" → 整改项按必过/选加分分级
- **坑**：测评前才发现日志留存不足（补历史日志来不及）；整改完没有持续合规机制，次年复查再挂

## 场景打单通用纪律

1. **先问触发事件**：场景商机的预算藏在触发事件里（事故/指标/到期/检查），触发不痛方案再好也不买
2. **给场景化成本**：通用折扣话术失效，要用场景单位成本（每路直播/每台设备/每次大促）
3. **留数据钩子**：每个场景设计一个可量化的试点指标，为下一阶段续费与 Upsell 埋点（承接见 `account-deepening.md`）
