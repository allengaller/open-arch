# 存量客户经营与续费保卫

SA 考核挂客户消费增量——存量经营不是售后善举，是 SA 的本职战场。签单只是开始，用起来、用得多、一直用，才是赢。

## 经营节奏

| 动作 | 频率 | 内容 |
|---|---|---|
| 架构巡检 | 季度 | 高可用/安全/性能/成本四维体检（打分工具用 `aliyun-waf` 技能 checklist.yaml） |
| 成本回顾 | 季度或半年度 | 账单透视 + 优化项落地（流程见 `sa-playbooks/content/cost-optimization.md`） |
| QBR（季度/半年度业务回顾） | 半年度 | 面向客户领导层：业务回顾 → 架构健康 → 成本 → 下一步路线图 |
| 到期与续费管理 | 合同到期前 90 天启动 | 续费方案、降量谈判、资源规划 |

**客户健康分**（量化经营，预警先于流失）：由消费趋势（环比增速）、资源利用率、工单量与满意度、关键人变动、产品覆盖广度加权而成。健康分下滑优先于商机分配处置——存量流失的损失通常是同等新签的 3-5 倍获客成本。

## 流失预警信号

- 消费信号：账单连续环比下滑、包年资源到期不续、核心实例释放
- 技术信号：新开通竞品产品、迁移类咨询、工单满意度骤降、故障后沉默
- 组织信号：技术负责人/关键决策人离职或轮岗、采购流程收紧、预算削减传闻
- 行为信号：QBR 推迟或拒绝参加、SA 的消息回复变慢

预警处置：48 小时内升级 BD，共同制定保卫计划（高层拜访 + 技术价值再证明 + 商务方案）。

## Upsell / Cross-sell 挖掘

**挖掘动作按场景**：

| 场景 | 挖掘点 |
|---|---|
| 架构巡检 | 单点未治理 → 高可用产品；自建组件 → 托管服务（Replatform 深化）；安全裸奔 → 安全产品矩阵 |
| 成本优化 | 用省下的钱换新场景预算："省 50 万，投 AI 试点"比"再买 50 万资源"好卖十倍 |
| 业务事件 | 大促/开学/发版 → 弹性扩容与压测；出海 → 全球化网络与合规；数据合规新规 → 改造项目 |
| 技术趋势 | AI/大模型试点（见 `ai-solutions.md`）、容器化/Serverless 改造、数据资产化 |
| 组织变化 | 新 CTO 上任 → 架构评审切入；新业务线 → 独立账号规划与 Landing Zone 扩展 |

**Upsell 的话术骨架**：巡检发现的具体问题 → 不处理的量化风险 → 处理方案的投入产出 → 同行业标杆案例。用客户自己的监控数据和账单说话，不用行业恐吓。

## QBR 结构

1. **业务回顾**（客户业务语言）：上周期业务成果、云支撑的关键事件（大促/发版/故障率）
2. **架构健康**：巡检得分趋势、已修复项、待治理项与优先级
3. **成本回顾**：消费结构、已落地的节省、下周期成本预测
4. **路线图**：下周期业务计划 → 云侧支撑方案 → 投入计划（这就是下一张订单的雏形）

QBR 的本质：把"供应商汇报"做成"客户的 IT 规划会"——客户领导层参加的 QBR，才是真 QBR。

## 续费保卫

- **到期前 90 天启动**：盘点到期资源与消费预测 → 续费方案（续费折扣 + 增购打包）→ 提前走客户采购流程（政企客户流程 1-3 个月，90 天是底线不是提前量）。
- **降量谈判**：客户砍预算时的换法——用更大承诺量/长约换更低单价，而不是被动接受降配；提供架构替代方案（降配不影响业务的优化点）保住基础盘。
- **故障是保卫战**：重大故障后的 30 天是续费高危期，按"重大故障中的 SA"（下节）处置，把危机变成信任修复。
- **不可救药的流失**：业务关停、被集团统一收编——体面退出，保留关系等回旋（客户的人会流动，下一家可能再来）。

## 重大故障中的 SA

重大故障（客户业务受损）是客户关系的压力测试，SA 动作分三段：

- **黄金 24 小时**：不谈责任先谈恢复——协同支持/产品侧给止血方案；客户侧事实同步保持单一口径（与 BD 事先对齐）；客户领导层安抚由 BD+SA 高配完成，SA 只讲技术事实与恢复预期。
- **复盘期（1-2 周）**：根因报告诚实不含糊（回避根因比故障本身更伤信任）；整改路线图带责任人与时间表；整改项挂进季度巡检持续跟踪。
- **信任修复（30 天）**：整改进展主动汇报（不等客户来问）；提供补偿性技术投入（架构优化专项、压测护航）。

**纪律**：SA 不代表公司认责赔偿（商务口径归 BD/法务）；不向客户披露未经确认的根因猜测；不说"单机故障属正常范围"。

## 客户分级投入模型

| 级别 | 标准 | SA 投入 |
|---|---|---|
| 战略客户 | 行业标杆、年消费头部、有高层关系 | 专属 SA，季度 QBR + 半年度高层技术汇报，定制路线图 |
| 重点客户 | 消费稳定、有增长空间 | 分片覆盖，季度巡检 + 年度 QBR |
| 长尾客户 | 低消费、标准化需求 | 伙伴/服务体系承接，SA 只处理升级问题（借力模型见 `acquisition-channels.md`） |

## 关键话术

- 存量是最高 ROI 的战场：赢单率 存量 Upsell > 转介绍 > 新线索，流失损失是获客成本的数倍。
- 巡检不是为了打分，是为了用客户自己的数据开出下一张订单。
- 续费从签约第一天开始：交付质量、巡检节奏、QBR 存在感，都是续费谈判的筹码。
- 省钱是最好的 Upsell 开场白：帮客户省钱的人，才有资格谈新投入。
