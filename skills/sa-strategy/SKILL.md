# SA 策略：基于全面理解的路径选择

策略 = 全面理解之上的路径选择。**先备齐输入，再进框架——没有全面理解的策略是赌注。**

    输入（全面理解） → 五步框架（态势→目标→路径→预案→评审） → 输出（作战卡/年度策略） → 作战室对齐生效

| 场景 | 用哪份 |
|---|---|
| 策略总框架：态势盘点、目标与胜负手、红队评审、常见谬误 | `content/strategy-framework.md` |
| 攻单策略：胜负手、战线选择、节奏控制、作战卡模板 | `content/deal-strategy.md` |
| 存量经营策略：四种主线、场景地图、防线与节奏表 | `content/account-strategy.md` |

工作方式：

1. **输入检查（出策略前必过）**：客户与协同方各角色视角卡用 `sa-perspectives` 技能；商机事实与打单机制用 `cloud-sa-playbook` 技能（线索路由、铁三角、竞争、经营各篇）；信息逐项标注"事实 / 推断 / 未知"，未知项转化为待办动作而不是拍脑袋补齐。
2. **框架套用**：按五步走——态势、目标（含量化与底线）、胜负手（≤3 个）、路径与节奏点、预案 If-then；策略一页纸，带版本号与复审时间。
3. **评审生效**：红队质询通过后 BD/SA 双签，进作战室按节奏点推进；形势变化触发策略复审，而不是临时即兴应变。
4. **产出物统一交付**：商机作战卡、年度客户策略用 `export_deliverable` 打包交付。

注：模板是通用骨架，各团队作战卡格式不同，按实际格式套用；策略中涉及报价、折扣与商务承诺处，一律以 BD 口径与管理层审批为准。
